# 前端页面验收 Checklist

> **适用范围**：所有前端原型页面的最终交付验收，与框架无关
> **来源**：从既有原型工程的页面验收清单提炼，去除工程专属检查项

---

## 使用方式

页面交付前，按页面类型选择对应章节逐条检查：

| 页面类型 | 必检章节 |
| :--- | :--- |
| 列表页 | §1、§2、§3、§5、§6 |
| 详情页 | §1、§4、§5、§6 |
| 新增/编辑页 | §1、§4、§5、§6 |
| 组合模块 | 全量检查 |

---

## 1. 真相源对齐

| 检查项 | 标准 |
| :--- | :--- |
| PRD 已阅读 | 当前页面对应 PRD 已核对 |
| 字段清单已阅读 | 当前页面字段口径来自字段清单 |
| 参考页已核对 | 已打开最相近页面实现，不是凭经验发挥 |
| 历史实现差异已核对 | 若参考页为老实现，已核对是否与最新 PRD 一致 |

---

## 2. 列表页检查

### 结构检查

| 检查项 | 标准 |
| :--- | :--- |
| 页面骨架 | 标题区、查询区、工具条、表格、分页齐全 |
| 查询字段 | 与 PRD 一致，无擅自新增或删减 |
| 查询区节奏 | 默认展示不超过 2 行，超出部分通过展开/收起承载 |
| 工具条分区 | 批量操作在左，列设置等弱操作在右 |
| 勾选列 | 若 PRD 要求批量操作，则勾选列、全选、已选计数齐全 |
| 列顺序 | 与 PRD 表格列从左到右**逐列一致** |
| 列设置 | 只管理业务字段，不含勾选列/操作列等系统列 |
| 长文本 | 截断、hover 提示、展开逻辑符合 PRD |
| 分页 | 总数、页码、页大小切换正常 |

### 交互检查

| 检查项 | 标准 |
| :--- | :--- |
| 行操作 | 所有行操作均按 PRD 覆盖 |
| 批量操作 | 所有批量操作均按 PRD 覆盖 |
| 风险动作确认 | 使用语义化确认弹窗（"确认取消"而非"确定"），不用原生对话框 |
| 跳转入口 | 链接色字段、查看按钮均可正常跳转 |
| 反馈文案 | 与 PRD 要求一致，不用模糊通用文案 |
| 不可操作态 | 应隐藏则隐藏，不展示"禁用但根本不该出现"的假入口 |

---

## 3. 列表页 Mock 数据检查

| 检查项 | 标准 |
| :--- | :--- |
| 条数达标 | 满足 PRD 最低条数（默认 ≥ 10 条） |
| 状态覆盖 | 每种状态至少 2 条 |
| 类型覆盖 | 每种业务类型至少 1 条 |
| 枚举合法性 | 所有枚举值来自字段清单，不自造清单外文案 |
| 空值样例 | 已保留必要的空值场景，空值统一展示 `-` |
| 引用一致性 | 外键引用（单号/ID）在被引用模块中实际存在 |

---

## 4. 详情页 / 表单页检查

| 检查项 | 标准 |
| :--- | :--- |
| 页头结构 | 标题、状态 Badge、头部动作区结构正确 |
| 返回列表位置 | 位于动作组最左侧 |
| 信息分区 | 分组顺序与 PRD / 字段清单一致 |
| 只读态 | 使用文本展示，不用 disabled 输入框冒充只读 |
| 子表 / Tabs | 该有的子表、历史记录、关联查询均已接入 |
| 风险动作 | 弹窗确认文案使用语义化动词 |
| 空值占位 | 统一使用 `-` |
| 制单信息 | 创建/修改/关闭等制单信息**固定置底** |

---

## 5. 代码层检查

| 检查项 | 标准 |
| :--- | :--- |
| 原生弹窗 | `window.confirm` / `window.alert` 出现次数必须为 0 |
| 硬编码业务数据 | `=== "具体单号"` 等硬编码判断出现次数必须为 0 |
| 风险动作按钮文案 | 确认按钮使用"确认取消/确认关闭/确认审核"等语义化动词 |
| 构建通过 | `npm run build`（或等效命令）无报错 |

---

## 6. 运行态检查

| 检查项 | 标准 |
| :--- | :--- |
| 页面可打开 | 目标页面在浏览器中可实际访问 |
| 查询区运行态 | 间距、对齐、展开/收起逻辑正确 |
| 表格运行态 | 行高、固定列、hover 联动、勾选列正确 |
| 图标运行态 | icon **实际渲染尺寸**正确（不只看 className） |
| 弹窗运行态 | 弹窗层级、按钮位置、文案正常 |
| 详情页运行态 | 头部动作、信息分区、子表渲染正常 |

---

## 交付判断

只有同时满足以下三点，页面才算完成：

1. **PRD 对齐了**
2. **代码自检通过了**
3. **运行态看过了**

> "代码里写了 18px"不等于"页面上真的显示 18px"——必须用运行态确认。
