## 2. 页面结构

详情页从上到下固定为：

| 顺序 | 区域 | 说明 |
| :---: | :--- | :--- |
| 1 | 页面标题区 | 标题、状态、右侧动作 |
| 2 | 关键信息区 | 可选；展示编码、名称、状态、所属组织等高频识别信息 |
| 3 | 信息分组区 | 按字段清单分组展示完整字段 |
| 4 | 子表/只读列表 | 联系人、地址、配置明细、商品行、执行明细等 |
| 5 | 上下游/执行结果 | 如有上游来源、下游结果、回写状态、失败原因，在本区或 Tab 展示 |
| N | 制单/同步信息 | 固定置底 |

## 3. 页头与动作

| 元素 | 规则 |
| :--- | :--- |
| 标题 | `{模块名} {编码}` 单行展示；无编码时使用名称 |
| 状态 | 如有状态字段，在信息分组区用 Badge 展示；状态值来自字段清单 |
| 返回列表 | 使用 `BackToListButton`（幽灵按钮 + ArrowLeft 图标），置于页头操作区最左侧 |
| 右侧动作 | 编辑、启用、禁用、提交、撤销提交、审核、驳回、反审核、下推、取消、关闭、重试、删除等页面级动作 |
| 不可用动作 | 直接不展示，不渲染 disabled 假入口 |

### 3.1 动作矩阵

| 操作 | 显示条件 | 点击结果 | 二次确认 | 成功反馈 |
| :--- | :--- | :--- | :---: | :--- |
| 返回列表 | 始终 | 返回列表页 | 否 | - |
| 编辑 | 支持编辑且当前记录可编辑 | 进入编辑页 | 否 | - |
| 启用 | 当前禁用且有权限 | 变为启用 | 是 | 启用成功 |
| 禁用 | 当前启用且满足禁用条件 | 变为禁用 | 是 | 禁用成功 |
| 提交 | 草稿 / 待提交 / 已驳回且有权限 | 变为待审核 | 是 / 否 | 提交成功 |
| 撤销提交 | 待审核且有权限 | 回到可编辑状态 | 是 | 撤销提交成功 |
| 审核 | 待审核且有权限 | 变为已审核 | 是 | 审核成功 |
| 驳回 | 待审核且有权限 | 变为已驳回 / 待提交 | 是 | 驳回成功 |
| 反审核 | 已审核且满足反审核条件 | 回到指定目标状态 | 是 | 反审核成功 |
| 下推 | 已审核 / 可执行且满足下推条件 | 生成下游对象或执行任务 | 是 | 下推成功 / 下推完成 |
| 取消 | 当前状态允许取消且无下游拦截 | 变为已取消 | 是 | 取消成功 |
| 关闭 | 当前状态允许关闭且满足关闭条件 | 变为已关闭 | 是 | 关闭成功 |
| 重试 | 执行失败且支持重试 | 重新执行失败任务 | 是 | 重试成功 |
| 删除 | 业务明确允许且无引用 | 删除并返回列表 | 是 | 删除成功 |

## 4. 信息分组

| 顺序 | 分组 | 字段 | 布局 | 展示说明 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | 基本信息 | [字段1、字段2] | Grid 4列 | 关键身份、分类、状态等 |
| 2 | [业务信息] | [字段] | Grid 4列 | 按字段清单分组顺序展示 |
| 3 | [联系/地址/配置明细] | [子表字段] | Table / Grid | 子表只读展示 |
| 4 | 上下游关联 | 上游单据、下游单据、下推状态、回写状态等 | Table / Link List / Tabs | 有跳转权限时可点击联查；无权限展示普通文本 |
| 5 | 执行结果 | 执行状态、最近失败原因、最近回写时间、错误明细等 | Grid + Table | 失败原因展示完整文本，错误明细可折叠 |
| N | 制单/同步信息 | 创建人、创建时间、修改人、修改时间等 | Grid 4列 | 固定置底 |

## 5. 字段展示规则

| 场景 | 规则 |
| :--- | :--- |
| 布局 | Label 在上，Value 在下；简单字段用 4 列 Grid |
| 空值 | `-` |
| 主数据引用 | `{Code} {Name}` |
| 枚举字段 | 使用字段清单定义的中文枚举值 |
| 长文本 | 跨 2-4 列并放在所属分组最后 |
| JSON 字段 | 解析后展示关键字段，不直接展示 JSON 原文 |
| 子表 | 使用只读表格；字段顺序与字段清单或本文定义一致 |
| 上下游单据 | 有跳转权限时用链接色；无权限时普通文本；空值为 `-` |
| 执行失败原因 | 列表可摘要，详情页展示完整原因；多条错误用只读表格 |
| 制单/同步信息 | 固定置底，不插在业务信息中间 |

## 7. Mock 数据要求

- 至少 3 条记录可进入详情页。
- 至少 1 条展示完整子表，至少 1 条子表为空。
- 至少 1 条展示启用状态，至少 1 条展示禁用状态。
- 如支持状态流转，至少覆盖草稿、待审核、已审核、已驳回等主要状态。
- 如支持下推、取消、关闭、回写，至少覆盖有上游、无下游、多个下游、执行失败、部分成功、已取消、已关闭等详情状态。
- 至少 1 条覆盖空值兜底和长文本。
- 枚举值必须来自字段清单，不得使用真实敏感数据。
