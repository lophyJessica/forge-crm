## 3. 表单分组与控件

### 3.1 控件选型

| 字段场景 | 控件类型 | 使用规则 | 需要说明的输入约束 |

### 3.4 常见输入约束规范

| 场景 | 默认规则 | 说明 |
| :--- | :--- | :--- |
| 文本去空格 | 保存前去首尾空格 | 名称、编码等字段不能只输入空格 |
| 最大长度 | 必须在本文件写明或引用字段清单 | AI 生成页面时要配置 `maxLength` 或输入提示 |
| 字符限制 | 编码类字段需说明允许字符 | 不要只写“编码”，要写是否允许中文、空格、特殊符号 |
| 唯一性 | 编码、名称、组合键等必须写清校验范围 | 如“同组织下名称唯一”“全局编码唯一” |
| 条件必填 | 必须写清触发条件 | 如“类型=外部客户时，外部客户编码必填” |
| 只读字段 | 使用只读展示，不允许用户输入 | 系统生成、系统带出、审核状态、启用/禁用状态默认不进表单 |
| 禁用数据 | 关联选择时默认不可新选 | 历史引用展示按详情规则处理 |
| 空值保存 | 选填字段清空后按后端约定保存 | 页面展示空值统一为 `-`，表单内按控件空态展示 |

## 5. 校验规则

### 5.1 校验触发时机

| 触发时机 | 适用场景 | 校验内容 | 反馈方式 |
| :--- | :--- | :--- | :--- |
| 输入时 | 长度、字符、数值范围、非法字符 | 可即时判断的格式类约束 | 字段下方错误 / 字符计数 / 禁止继续输入 |
| 失焦时 | 编码、名称、手机号、邮箱、日期等 | 格式、空格、轻量重复校验 | 字段下方错误 |
| 选择时 | 关联主数据、枚举、日期范围 | 选项合法性、上下游联动、起止关系 | 字段下方错误或清空下游字段 |
| 保存时 | 全量字段、子表、唯一性、引用约束 | 必填、条件必填、重复、引用、状态 | 阻断保存并定位到错误字段 |
| 保存并提交时 | 保存校验 + 提交前校验 | 表单完整性、状态是否允许提交 | 先提示保存错误；保存成功后再提示提交错误 |

### 5.2 主表字段校验

| 校验项 | 校验规则 | 触发时机 | 错误提示 | 是否阻断保存 |
| :--- | :--- | :--- | :--- | :---: |
| 必填字段 | 字段清单标记为必填的字段不能为空；文本字段去首尾空格后不能为空 | 失焦 / 保存 | 请填写[字段名称] | 是 |
| 条件必填 | 满足指定条件时不能为空 | 条件变化 / 保存 | [条件]时，请填写[字段名称] | 是 |
| 长度限制 | 文本长度不得超过字段清单或本文件约定 | 输入时 / 保存 | [字段名称]不能超过[N]个字符 | 是 |
| 字符限制 | 编码等字段只能输入允许字符 | 输入时 / 保存 | [字段名称]仅支持[允许字符] | 是 |
| 格式限制 | 手机号、邮箱、URL、日期、编码格式等必须合法 | 失焦 / 保存 | [字段名称]格式不正确 | 是 |
| 数值范围 | 数值必须在最小值、最大值、小数位范围内 | 输入时 / 保存 | [字段名称]必须在[x]-[y]之间 | 是 |
| 日期关系 | 开始日期不得晚于结束日期；生效日期不得早于指定日期 | 选择时 / 保存 | [开始日期]不能晚于[结束日期] | 是 |
| 唯一字段 | 编码、名称或组合唯一键不可重复 | 失焦 / 保存 | [字段名称]已存在，请修改后保存 | 是 |
| 引用约束 | 被引用记录不可修改关键字段 | 保存 | 当前记录已被引用，不允许修改[字段名称] | 是 |
| 只读字段 | 只读字段不允许提交用户修改值 | 保存 | 前端不展示可编辑入口；接口兜底拦截 | 是 |
| 明细数量 | 数量、金额、可执行数量不满足字段清单或业务 PRD | 输入时 / 保存 | 请检查第 {行号} 行[字段名称] | 是 |
| 上游联动 | 上游来源变化后，下游字段或明细不再合法 | 选择时 / 保存 | 请重新选择[字段名称] | 是 |

### 5.3 重复校验说明

| 校验对象 | 校验范围 | 新增页规则 | 编辑页规则 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| [编码] | 全局唯一 / 组织内唯一 | 输入值不得与已有记录重复 | 排除当前记录后不得重复 | 明确是否区分大小写 |
| [名称] | 全局唯一 / 组织内唯一 / 类型内唯一 | 按业务规则校验 | 排除当前记录后校验 | 如允许重名，写「不校验」 |
| [组合唯一键] | [字段A + 字段B] | 组合值不得重复 | 排除当前记录后校验 | 如组织 + 类型 + 名称 |
| 子表行 | 同一主记录下 | 行内 [字段组合] 不得重复 | 行内 [字段组合] 不得重复 | 错误需定位到具体行 |

### 5.4 错误展示规则

| 场景 | 展示位置 | 展示规则 |
| :--- | :--- | :--- |
| 单字段错误 | 字段下方 | 显示具体错误，不只提示“校验失败” |
| 子表行错误 | 子表行内字段下方 / 行错误摘要 | 必须能定位到第几行、哪个字段 |
| 多个错误 | 页面顶部错误摘要 + 字段级错误 | 点击摘要可定位到首个错误字段 |
| 保存失败 | Toast / 表单错误 | 已知校验错误展示字段级原因；未知服务异常展示通用错误 |
| 唯一性冲突 | 字段下方或 Toast | 优先定位字段；组合唯一可展示在相关字段组下方 |
| 未保存离开 | Modal 二次确认 | 文案说明离开后不会保存当前修改 |

## 7. Mock 数据要求

- 新增页覆盖默认值、必填校验、唯一性校验。
- 编辑页覆盖可编辑记录、不可编辑记录、被引用记录。
- 如支持「保存并提交」，Mock 需覆盖保存成功后提交成功、保存校验失败、提交状态不匹配。
- 若有子表，至少 3 行，覆盖默认项、空值、删除拦截。
- 若有商品行、数量行或执行明细，至少覆盖数量为 0、超出可执行数量、行级重复、行级只读、部分行不可编辑。
- 若有上游带出字段，至少覆盖上游选择后带出、切换上游后清空下游字段、上游失效时阻断保存。
- 必须提供至少 1 组字段长度超限、字符非法、格式错误、数值越界、日期关系错误的校验样例。
- 必须提供至少 1 组主表重复、子表行重复、组合唯一键重复的校验样例；如模块不支持某类重复校验，明确写「不适用」。
- 必须提供至少 1 组条件必填样例，例如某枚举选项触发额外字段必填。
- 必须提供至少 1 组未保存离开确认样例。
- 枚举值必须来自字段清单，不得使用真实敏感数据。
