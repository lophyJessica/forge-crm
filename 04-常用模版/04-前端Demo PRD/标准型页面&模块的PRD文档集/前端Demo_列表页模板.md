## 3. 查询区

### 3.1 查询控件选型

| 字段场景 | 控件类型 | 使用规则 |
| :--- | :--- | :--- |
| 单值文本 | `Input` | 编码、名称、外部编号等 |
| 批量精确 | `BatchSearchInput` | 多编码、多单号、多条码；不得用 `Textarea` |
| 枚举单选 | `Select` | 状态、类型、是否类字段；空值选项显示「全部」 |
| 关联主数据 | `SelectWithSearch` | 展示 `{Code} {Name}`，支持编码/名称搜索 |
| 日期范围 | `DateRange` | `YYYY-MM-DD` |
| 日期时间范围 | `DateTimeRange` | `YYYY-MM-DD HH:mm:ss` |

### 3.2 查询字段清单

### 3.3 查询交互

| 交互 | 规则 |
| :--- | :--- |
| 搜索 | 刷新列表并回到第一页；成功不额外 Toast |
| 重置 | 清空所有查询条件，刷新默认列表并回到第一页 |
| 展开/收起 | 查询项超过工程默认容量时显示 |
| 空条件搜索 | 允许，返回默认最新列表数据 |

### 5.2 展示规则

| 场景 | 规则 |
| :--- | :--- |
| 空值 | `-` |
| 可排序列 | 仅金额列和时间列显示排序图标，其他列纯文本表头不可排序 |
| 主数据引用 | `{Code} {Name}` |
| 枚举字段 | 使用字段清单定义的中文枚举值 |
| 长文本 | 列表截断，详情展示完整 |
| 上游/下游单据 | 有跳转权限时用链接色；无权限时展示普通文本 |
| 执行失败原因 | 列表只展示摘要，完整原因在详情页或结果弹窗展示 |
| 操作列 | 默认文字动作；不可操作时不展示 |
| 列设置 | 只管理业务列，不管理操作列、勾选列、序号列 |

## 6. 行操作矩阵

| 操作 | 显示条件 | 点击结果 | 二次确认 | 成功反馈 |
| :--- | :--- | :--- | :---: | :--- |
| 查看 | 始终 | 进入详情页 | 否 | - |
| 编辑 | 支持编辑且当前记录可编辑 | 进入编辑页 | 否 | - |
| 启用 | 当前禁用且有权限 | 变为启用 | 是 | 启用成功 |
| 禁用 | 当前启用且满足禁用条件 | 变为禁用 | 是 | 禁用成功 |
| 提交 | 草稿 / 待提交 / 已驳回且有权限 | 变为待审核 | 是 / 否 | 提交成功 |
| 撤销提交 | 待审核且有权限 | 回到可编辑状态 | 是 | 撤销提交成功 |
| 审核 | 待审核且有权限 | 变为已审核 | 是 | 审核成功 |
| 驳回 | 待审核且有权限 | 变为已驳回 / 待提交 | 是 | 驳回成功 |
| 反审核 | 已审核且满足反审核条件 | 回到指定目标状态 | 是 | 反审核成功 |
| 下推 | 已审核 / 可执行且满足下推条件 | 生成下游对象或执行任务 | 是 | 下推成功 / 下推完成 |
| 取消 | 当前状态允许取消且无下游拦截 | 变为已取消 | 是 | 取消成功 |
| 关闭 | 当前状态允许关闭且满足关闭条件 | 变为已关闭 | 是 | 关闭成功 |
| 重试 | 执行失败且支持重试 | 重新执行失败任务 | 是 | 重试成功 |
| 删除 | 业务明确允许且无引用 | 删除记录 | 是 | 删除成功 |

## 8. Mock 数据要求

- 至少 10 条列表数据。
- 状态/类型枚举每个主要值至少 2 条。
- 至少 1 条可编辑、1 条不可编辑、1 条可启用、1 条可禁用。
- 如支持状态流转，至少覆盖草稿、待审核、已审核、已驳回等主要状态。
- 如支持下推、取消、关闭或回写，至少覆盖可下推、已下推、部分成功、失败、已取消、已关闭等关键状态。
- 至少 1 条有空值兜底，至少 1 条有超长文本。
- 枚举值必须来自字段清单，不得使用真实敏感数据。
