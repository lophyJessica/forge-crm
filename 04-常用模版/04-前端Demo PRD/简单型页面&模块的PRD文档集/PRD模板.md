### 1.1 简单型适用边界

- 简单型适用于无审核流、无外部系统同步、无下游单据生成的主数据 CRUD 或轻量配置模块。
- 本文件同时承担主 PRD 和 Demo PRD 职责，不再单独写主 PRD；业务规则直接写在本文件的业务背景与流程、功能清单映射等章节。
- **先选维护形态**：字段少、以取值维护为主、或「类别树 + 叶子列表」→ 轻量配置（弹窗）；字段分组多、需操作日志 → 标准主数据（独立页）。详规见 UI 规范库 `08`。
- 若存在提交、审核、下推、取消、关闭、上下游回写等动作，或业务规则超过 15 条，说明模块复杂度超出简单型范围，应改用标准型模板（单独写主 PRD + 拆分 Demo PRD）。
- 若页面为外部只读资料，只保留列表、详情、导出等入口，不展示新增、编辑、删除等假入口。

## 五、列表页规范

### 5.1 查询区

> 不人工划分「默认可见 / 更多筛选」。具体行数、折叠与展开由前端工程统一承载。本文只定义查询字段、控件类型、查询逻辑和展示顺序。

**筛选区布局**：6 列网格（`grid xl:grid-cols-6`），控件宽度自适应（`w-full`）；查询/重置按钮在筛选字段下方单独一行右对齐（`mt-4 flex justify-end`）。

#### 5.1.1 查询控件选型

| 字段场景 | 控件类型 | 使用规则 | 示例字段 |
| :--- | :--- | :--- | :--- |
| 单值文本精确搜索 | `Input` | 只输入一个值；用于编码、名称、外部编号等单字段搜索 | 编码、名称、外部来源单号 |
| 批量精确搜索 | `BatchSearchInput` | 支持换行或逗号分隔多个值；用于批量查编码/单号；不得用 `Textarea` 替代 | 商品编码、单据号、条码 |
| 枚举单选 | `Select` | 枚举值较少，无需搜索；空值选项显示「全部」 | 使用状态、类型、是否启用 |
| 关联主数据搜索 | `SelectWithSearch` | 关联有独立编码的主数据，展示 `{Code} {Name}`，支持编码/名称搜索 | 组织、仓库、客户、供应商、门店 |
| 日期范围 | `DateRange` | 精确到日期，格式 `YYYY-MM-DD` | 创建日期、业务日期 |
| 日期时间范围 | `DateTimeRange` | 精确到秒，格式 `YYYY-MM-DD HH:mm:ss` | 创建时间、同步时间 |

#### 5.1.2 查询字段清单

| 顺序 | 查询字段 | 控件类型 | 查询逻辑 | placeholder / 默认文案 | 备注 |
| :---: | :--- | :--- | :--- | :--- | :--- |
| 1 | [字段名] | Input / Select / SelectWithSearch / DateRange / DateTimeRange / BatchSearchInput | 精确 / 模糊 / 范围 / 批量精确 | [请输入/全部/请选择日期范围] | [说明] |

#### 5.1.3 查询区交互

| 交互 | 规则 |
| :--- | :--- |
| 搜索 | 点击「搜索」后刷新列表，回到第一页 |
| 重置 | 清空所有查询条件，刷新默认列表，回到第一页 |
| 展开/收起 | 当查询项超过工程默认展示容量时显示；按钮位于查询区右侧操作组最左 |
| 空条件搜索 | 允许，返回默认最新列表数据 |
| 搜索成功 | 无额外 Toast，直接刷新列表 |
| 搜索失败 | Toast：`搜索失败，请检查查询条件后重试` |

### 5.2 页面标题区与列表工具条

#### 5.2.1 页面标题区

| 元素 | 规则 |
| :--- | :--- |
| 标题 | 使用页面名称，如「[模块名]」 |
| 副标题 | 简单型默认不写；除非本文件业务背景章节明确要求 |
| 右侧动作 | 只放页面级主动作，如「新增」 |

#### 5.2.2 按钮清单

| 位置 | 按钮 | 显示条件 | 点击结果 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 页头右侧 | 新增 | 支持新增且用户有权限 | 标准主数据：跳转新增页；轻量配置：打开新增弹窗 | 不支持新增时不展示 |
| 列表工具条右侧 | 导出 | 支持导出且用户有权限 | 导出当前筛选结果 | 文案用「导出」，不写「批量导出」 |
| 列表工具条右侧 | 列设置 | 工程具备时 | 打开列设置 | 只管理业务列 |
| 批量操作区 | 批量[动作] | 支持批量且已勾选 | 执行动作 | 简单型默认少用；无明确 PRD 不补 |

> 表格列顺序必须与本表自上而下一致。业务列进入列设置；操作列、勾选列、序号列不进入列设置。

#### 5.3.1 列定义

| 顺序 | 列名 | 字段名 | 宽度建议 | 对齐方式 | 展示规则 | 固定 | 空值 | 备注 |
| :---: | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | [主键/编码列] | [field] | 160px | 左对齐 | 链接色；标准主数据进详情，轻量配置打开查看弹窗 | 左固定 / 否 | `-` | 主入口字段优先可点击 |

| 3 | [枚举/状态列] | [field] | 120px | 居中 | Badge / 文本，枚举值来自字段清单 | 否 | `-` | 不自造枚举 |

| N | 操作 | - | 120px | 左对齐 | 文字动作（`TextAction`） | 右固定 | - | 系统列，不进入列设置 |

#### 5.3.2 展示规则

| 场景 | 规则 |
| :--- | :--- |
| 空值 | 统一展示 `-`，禁止展示中文破折号、空白或 `null` |
| 主数据引用 | 有独立业务编码的主数据统一展示 `{Code} {Name}` |
| 枚举字段 | 展示字段清单定义的中文枚举值，不自造文案 |
| 状态字段 | 可用 Badge；颜色不改变业务语义，PRD 未要求时不加整行底色 |
| 长文本 | 最多展示 1-2 行，超出省略；详情页展示完整内容 |
| 日期 | `YYYY-MM-DD` |
| 时间 | `YYYY-MM-DD HH:mm:ss` |
| 数量/金额 | 右对齐；小数位以字段清单为准 |
| 可排序列 | 仅金额列和时间列显示排序图标，其他列纯文本表头不可排序 |
| 操作列 | **左对齐**文字动作；不可操作时不展示假入口 |

#### 5.3.3 列设置

| 规则 | 说明 |
| :--- | :--- |
| 管理范围 | 只管理业务字段 |
| 不纳入列设置 | 操作列、勾选列、序号列、展开列 |
| 可配置项 | 显示/隐藏、排序、左固定 |
| 固定列 | 业务列只允许左固定；操作列固定右侧 |

## 六、详情页 / 查看弹窗规范

> **维护形态分流**：标准主数据写本节「独立详情页」；轻量配置删除独立详情页描述，改用「查看弹窗」，并遵守 UI 规范库 `08`（无操作日志、状态在内容区、标题+`×`+分割线）。

### 6.1 页面结构（标准主数据 · 独立详情页）

详情页从上到下固定为：

| 顺序 | 区域 | 说明 |
| :---: | :--- | :--- |
| 1 | 页面标题区 | 标题为 `{模块名} {编码}` 单行展示；右侧动作按钮 |
| 2 | 信息分组区 | 按字段清单分组展示完整字段；不设独立的关键信息卡片 |
| 3 | 子表/只读列表 | 如联系人、地址、同步记录等 |
| 4 | 操作日志 | 可折叠卡片，含日志表格 + 分页 |
| N | 制单信息 | 固定置底；仅详情页展示，新增/编辑页不展示 |

### 6.1b 查看弹窗结构（轻量配置）

| 顺序 | 区域 | 说明 |
| :---: | :--- | :--- |
| 1 | 标题区 | 左标题（如「查看资料项」），右 `×`；底部分割线 |
| 2 | 内容区 | Label+Value；**使用状态**作为内容区字段，不用标题栏徽章 |
| 3 | 底栏 | 分割线 + `关闭` + `编辑`（切入编辑弹窗，不跳页） |

轻量配置默认**不展示操作日志**；创建人/创建时间可在查看弹窗展示，新增/编辑弹窗不展示。

### 6.2 页头

| 元素 | 规则 |
| :--- | :--- |
| 标题 | `{模块名} {编码}` 单行展示（如 `商品 SKU-0001`），不使用大标题 + 副标题 |
| 状态 | 如有状态字段，用 Badge 展示在信息分组区内；页头不单独展示状态 |
| 右侧动作 | `BackToListButton`（icon + 幽灵按钮）放最左侧 + `编辑`、`启用/禁用` |
| 不可用动作 | 直接不展示，不渲染 disabled 假入口 |

### 6.3 信息分组

| 顺序 | 分组 | 字段 | 布局 | 展示说明 |
| :---: | :--- | :--- | :--- | :--- |
| 1 | 基本信息 | [字段1、字段2] | Grid 4列 | 关键身份、分类、状态等 |
| 2 | [业务信息] | [字段] | Grid 4列 | 按字段清单分组顺序展示 |
| 3 | [联系/地址/同步明细] | [子表字段] | Table / Grid | 子表只读展示 |
| N | 同步信息/制单信息 | 创建人、创建时间、同步时间等 | Grid 4列 | 固定置底 |

### 6.4 详情字段展示规则

| 场景 | 规则 |
| :--- | :--- |
| 布局 | Label 在上，Value 在下；简单字段用 4 列 Grid；长文本跨 2-4 列并放在所属分组最后 |
| 空值 | 统一展示 `-` |
| 主数据引用 | `{Code} {Name}` |
| JSON 字段 | 解析后展示关键字段，不直接展示 JSON 原文 |
| 子表 | 使用只读表格；字段顺序与字段清单或本文定义一致 |
| 制单/同步信息 | 固定置底，不插在业务信息中间；仅在详情页展示，新增/编辑页不展示 |

## 七、新增/编辑页或弹窗规范（如适用）

### 7.1 适用边界

- 简单型只有在本文件明确支持维护时才写新增/编辑。
- 外部只读资料不写新增/编辑，不展示新增/编辑入口。
- 启用/禁用类状态不放进表单编辑，统一通过列表操作列（或标准主数据详情页动作区）操作。
- **轻量配置**：新增/编辑用弹窗，结构同查看弹窗壳（标题+`×`+分割线+底栏）；底栏为 `取消` + `保存`。不写独立表单页章节时可把本节字段表直接当作弹窗内容区规格。

### 7.2 表单控件选型

| 字段场景 | 控件类型 | 使用规则 | 需要说明的基础约束 |
| :--- | :--- | :--- | :--- |
| 单行文本 | `Input` | 编码、名称、简称等 | 最大长度、是否去首尾空格、是否唯一 |
| 多行文本 | `Textarea` | 备注、说明、地址等长文本 | 最大长度、是否允许换行 |
| 数字 | `NumberInput` | 数量、排序号、比例、金额等 | 最小值、最大值、小数位、是否允许负数 |
| 日期 | `DatePicker` | 单个日期 | 可选范围、是否允许历史日期或未来日期 |
| 枚举 | `Select` / `RadioGroup` | 枚举少于 3 项可优先 `RadioGroup` | 枚举来自字段清单；空值文案为「请选择」 |
| 关联主数据 | `SelectWithSearch` | 展示 `{Code} {Name}` | 数据范围、禁用数据是否可选 |
| 系统生成/带出字段 | `ReadonlyText` | 新增页通常不展示，编辑页按需只读 | 不允许手工输入；空值展示 `-` |
| 多条码 | `BarcodeListEditor` | Tag/Chip 标签嵌入式输入框 | 主码/副码、⭐ hover 切主码、Backspace 删末尾、批量粘贴拆分、格式校验+防重、一键清空 |
| 金额 | `Input` + ¥ 前缀 | 零售价、批发价、采购价等 | 非负，2 位小数 |

### 7.3 表单分组

| 顺序 | 分组 | 字段 | 控件类型 | 显示/编辑规则 | 输入约束来源 |
| :---: | :--- | :--- | :--- | :--- | :--- |
| 1 | 基本信息 | [字段名] | Input / Select / SelectWithSearch / DatePicker / ReadonlyText | [规则] | 字段清单「取值说明 / 备注」 |
| 2 | [业务信息] | [字段名] | [控件] | [规则] | 字段清单 |
| N | 备注 | [字段名] | Textarea | 放在所属分组最后，跨列展示 | 字段清单 |

### 7.4 字段输入约束清单

> 简单型只要求写清新增/编辑真正会用到的基础约束。若某字段只读或不展示，不需要写前端输入限制；若字段清单与本表冲突，以字段清单为准。

| 字段 | 控件 | 是否必填 | 长度/字符限制 | 格式/范围限制 | 唯一/重复校验 | 校验时机 | 错误提示 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| [编码] | Input | 必填 / 不适用 | 最长 [N] 字符；允许字母、数字、`-`、`_` | [格式规则] | 新增时校验唯一；编辑时排除当前记录 | 失焦 / 保存 | [编码]已存在，请修改后保存 |
| [名称] | Input | 必填 | 最长 [N] 字符；保存前去首尾空格 | 不允许纯空格 | [同组织下唯一 / 不校验重复] | 失焦 / 保存 | 请填写[名称] |
| [类型/状态] | Select / RadioGroup | [必填性] | - | 只能选择字段清单枚举值 | 不适用 | 选择时 / 保存 | 请选择[字段名称] |
| [数值字段] | NumberInput | [必填性] | - | 最小 [x]，最大 [y]，小数 [n] 位 | 不适用 | 输入时 / 保存 | [字段名称]必须在[x]-[y]之间 |
| [日期字段] | DatePicker | [必填性] | - | 不早于/不晚于[日期] | 不适用 | 选择时 / 保存 | [字段名称]不在允许范围内 |
| [备注] | Textarea | 选填 | 最长 [N] 字符 | 允许换行 | 不适用 | 输入时 / 保存 | [字段名称]不能超过[N]个字符 |

### 7.5 基础校验规则

| 校验项 | 规则 | 触发时机 | 展示方式 |
| :--- | :--- | :--- | :--- |
| 必填校验 | 字段清单标记为必填的字段不能为空；文本字段去首尾空格后不能为空 | 保存 / 失焦 | 字段下方错误 |
| 条件必填 | 满足指定条件时字段不能为空 | 条件变化 / 保存 | 字段下方错误 |
| 长度校验 | 文本长度不得超过字段清单或本文件约定 | 输入时 / 保存 | 字段下方错误或字符计数 |
| 格式校验 | 手机号、邮箱、编码、日期等必须符合字段清单规则 | 失焦 / 保存 | 字段下方错误 |
| 数值范围 | 数值必须在允许范围内，且小数位符合规则 | 输入时 / 保存 | 字段下方错误 |
| 重复校验 | 编码、名称或组合键按本文件业务规则章节定义校验重复 | 失焦 / 保存 | 字段下方错误或 Toast |
| 只读保护 | 系统生成、系统带出、外部同步只读字段不得被用户修改 | 保存 | 前端不提供可编辑入口，接口兜底拦截 |

### 7.6 错误展示规则

| 场景 | 展示规则 |
| :--- | :--- |
| 单字段错误 | 在字段下方展示具体原因，不只写「校验失败」 |
| 多字段错误 | 保存时阻断，并定位到首个错误字段 |
| 重复冲突 | 优先在对应字段下提示；组合唯一冲突可用 Toast 补充 |
| 保存失败 | 已知校验错误展示字段级原因；未知服务异常 Toast：`保存失败，请稍后重试` |
| 未保存离开 | 点击返回列表时，如有修改，弹出二次确认 |

### 7.7 页头与保存动作

| 位置 | 按钮 | 显示条件 | 点击前校验 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 页头最左侧 | 返回列表 | 始终 | 如有未保存修改，弹出离开确认 | 使用 `BackToListButton`（icon + 幽灵按钮） |
| 页头右侧 | 保存 | 始终 | 必填、长度、格式、重复、只读保护 | 校验通过后保存 |

| 项目 | 新增页 | 编辑页 |
| :--- | :--- | :--- |

## 八、二次确认弹窗规格

> 启用/禁用/删除等风险动作必须二次确认。本表定义弹窗标题、正文和按钮文案，让 AI 生成时不需猜测。

| 触发操作 | 弹窗标题 | 弹窗正文 | 确认按钮文案 | 取消按钮文案 |
| :--- | :--- | :--- | :--- | :--- |
| 启用 | 确认启用 | 启用后该记录可被新业务选择，确认启用？ | **确认启用** | 取消 |
| 禁用 | 确认禁用 | 禁用后该记录不可被新业务选择，历史引用仍保留，确认禁用？ | **确认禁用** | 取消 |
| 删除 | 确认删除 | 删除后不可恢复，确认删除？ | **确认删除** | 取消 |

**弹窗文案要求**：
- 标题简洁（4-6 字），不重复操作名和字段名
- 正文必须告知操作后果（是否可恢复、影响范围）
- 确认按钮使用危险语义时，文案明确（如「确认删除」而非「确定」）
- 禁用类弹窗正文需说明"历史引用保留"，避免用户误以为会清空历史数据

## 十、Mock 数据要求

### 10.1 基础覆盖

- 至少 10 条列表数据；简单只读页可按真实字段结构构造虚构演示数据。
- 若存在状态/类型枚举，每个主要枚举至少覆盖 2 条；枚举值必须来自字段清单。
- 至少 1 条覆盖空值兜底，空值展示为 `-`。
- 至少 1 条覆盖超长文本截断。
- 支持详情页时，至少 3 条记录具备完整详情数据。
- 若支持新增/编辑，必须覆盖必填缺失、长度超限、格式错误、重复校验、数值/日期范围错误。
- 若支持新增/编辑，必须覆盖未保存离开确认。
- 不得使用真实公司、联系人、地址、手机号、邮箱、税号、银行账号。

### 10.2 业务关联性 Mock

> 除枚举和数量覆盖外，Mock 数据还需体现本模块与其他模块的引用关系，让 AI 生成的原型能演示真实业务场景。

| 关联场景 | Mock 要求 | 示例 |
| :--- | :--- | :--- |
| 被下游引用 | 至少 1 条记录处于"已被引用"状态，用于演示编码只读、不可删除等约束 | 商品已被销售订单引用 → 编辑页编码只读 |
| 多值字段 | 若存在多值字段（如条码、标签），至少 2 条记录覆盖多值场景 | 商品至少 3 条多条码，至少 1 条单条码 |
| 字典引用 | 若字段引用数据字典，至少覆盖 2 个不同字典项，至少 1 条引用已禁用字典项 | 商品分类覆盖"手机配件"和"耳机"，至少 1 条引用已禁用分类 |
| 关键字段为空 | 选填关键字段（如品牌、联系电话）至少 1 条为空，演示空值兜底 | 至少 1 条商品无品牌，至少 1 条仓库无联系电话 |
| 金额/数值差异 | 若有金额或数值字段，覆盖不同量级和精度，至少 1 条为 0 或边界值 | 客户期初欠款覆盖 0、小额、大额 |

## 十一、验收重点

| 验收项 | 标准 |
| :--- | :--- |
| 业务背景 | 模块定位、核心用户、核心场景写清，AI 能理解页面业务语境 |

| 页面骨架 | 标题区、查询区、工具条、表格、分页顺序正确 |
| 按钮位置 | 页面级、查询级、表格级、行内、详情页、表单动作位置正确 |
