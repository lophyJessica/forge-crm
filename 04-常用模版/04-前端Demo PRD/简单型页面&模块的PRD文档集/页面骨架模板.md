## ASCII线框绘制规则

### 宽度

- 简单页面控制在 80-100 字符，最多不超过 120 字符。
- 优先横向排布字段，一行放不下时才换行。
- 每行按内容实际所需宽度画，不刻意撑满到上限。

### 对齐

- 等宽字体查看时视觉对齐即可，允许中英文混排的轻微偏差。
- 字段之间用 1-3 个半角空格分隔。
- 表格列之间用单条竖线 `|` 分隔，列宽按表头文字最短宽度设定。

### 符号约定

| 元素 | 符号 |
| :--- | :--- |
| 输入框 | `[ ]` |
| 下拉框 | `[ v ]` |
| 按钮 | `[按钮文字]` |
| 勾选框 | `[ ]` / `[x]` |

### 面包屑

- 画在页面标题行左侧，格式：`面包屑：模块1 / 模块2 / 页面名`。
- 列表页画到模块名即可；新增/编辑/详情页画到具体页面名。

### 多字段处理

- 表格列数超宽时，优先扩宽线框；仍放不下时截断，保留 4-6 个核心字段 + 省略号 + 操作列。
- 其余字段用图外一行文字说明（如"隐藏字段：xxx、xxx，实际页面可横向滚动查看"）。
- 表格空行保留 2-3 行示意。

### 输出格式

- 用 markdown 代码块包裹，语言标记用 `text`。
