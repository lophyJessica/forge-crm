# 线索_Demo_新增编辑页

> **文档定位**：AI 生成线索新增编辑页前端原型的输入文档
> **字段定义**：字段名称、枚举值、必填性、类型和校验规则见《线索字段清单》，本文件只写页面呈现规则，严禁重复定义
> **版本**：V1.1 | 2026-08-13

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| 页面名称 | 线索新增 / 编辑 |
| 页面目标 | 创建新线索或编辑草稿态线索 |
| 新增路径 | `/leads/new` |
| 编辑路径 | `/leads/{id}/edit` |
| 骨架结构 | 表单卡片 + 固定底部操作栏 |

---

## 2. 固定底部操作栏

| 元素 | 规格 |
|------|------|
| 位置 | `fixed bottom-0 right-0`，宽度与表单卡片一致 |
| 按钮顺序 | `返回列表` → `保存草稿` → `提交` |
| `保存草稿` | 次要按钮，点击动作后按《线索主PRD》进入 `DRAFT` |
| `提交` | 主按钮（实心），点击动作后按《线索主PRD》进入 `PENDING_ASSIGN` 并触发 AI 评分 |

---

## 3. 表单卡片

### 3.1 基本信息

卡片标题：**基本信息**。栅格：4 列桌面端。

| 字段 | 控件类型 | 详细规格 |
|------|---------|---------|
| 线索来源 | Select | 选项及枚举文案引用《线索字段清单》 |
| 公司名称 | Input | placeholder：请输入公司名称；长度和类型引用《线索字段清单》 |
| 联系人 | Input | placeholder：请输入联系人姓名；长度和类型引用《线索字段清单》 |
| 手机号 | Input | placeholder：请输入手机号；格式、唯一性和必填关系引用《线索字段清单》 |
| 邮箱 | Input | placeholder：请输入邮箱；格式、唯一性和必填关系引用《线索字段清单》 |
| 职位 | Input | placeholder：请输入职位；长度和类型引用《线索字段清单》 |
| 所属行业 | Select | 选项及枚举文案引用《线索字段清单》 |
| 所在地区 | Cascader | 级联选择；类型和层级引用《线索字段清单》；placeholder：请选择所在地区 |
| 线索备注 | Textarea | placeholder：请输入备注信息；长度和类型引用《线索字段清单》 |

**页面交互规则**：手机号与邮箱至少填写一个；为空时提示“手机号和邮箱至少填写一个”。字段本身的必填性、格式和唯一性以《线索字段清单》为准。

## 4. 编辑模式差异

| 字段 | DRAFT 草稿态 | 其他状态 |
|------|:-----------:|:------:|
| 全部字段 | 可编辑 | 只读（编辑仅限 DRAFT 态） |

---

## 5. 交互规范

### 5.1 保存草稿
- **页面交互规则**：允许暂存未完成表单；字段格式错误时标红并阻断保存。
- 点击动作后按《线索主PRD》进入 `DRAFT`
- API 调用后提示"草稿已保存"

### 5.2 提交
- 按《线索字段清单》校验字段完整性、格式和唯一性，并按《线索主PRD》执行去重。
- 校验通过 → 点击动作后进入 `PENDING_ASSIGN`，触发 AI 评分。
- **页面交互规则**：校验失败时标红对应字段，Toast “请完善必填信息”。
- **页面交互规则**：去重失败时 Toast “该手机号/邮箱已存在线索 XXX”。

### 5.3 返回
- 点击「返回列表」→ 回到上一页，不保存
