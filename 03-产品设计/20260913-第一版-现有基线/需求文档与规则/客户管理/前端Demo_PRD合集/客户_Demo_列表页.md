# 客户_Demo_列表页

> **版本**：V2.1 | 2026-08-13
> **页面类型**：PC Web 列表页
> **前置文档**：《客户主PRD》《客户字段清单》
> **SSOT 声明**：客户正式档案来自 ERP，页面不提供新增、编辑或删除客户能力。
> **字段约束**：字段定义与展示口径引用《客户字段清单》。ERP 同步标识是技术元数据提示，不是客户业务字段。

---

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| 页面名称 | 客户管理 |
| 页面路径 | `/accounts` |
| 页面目标 | 查询 ERP 客户快照，并查看 CRM 关系聚合与流失风险 |
| 主要用户 | 销售、销售主管、系统管理员、只读审计角色 |
| 页面骨架 | 页头 → 风险 Tab → 查询区 → 工具条 → 表格 → 分页 |
| 默认排序 | 本模块例外：进行中商机优先，其次 ERP 客户创建时间倒序；主动排序以用户选择为准 |
| 每页条数 | 默认 20 条，可切换 20 / 50 / 100 |
| 详情入口 | 客户编号或公司名称链接 |

页面原则：

- 首屏直接展示客户工作列表，不做介绍页。
- 页面任何位置都不得出现“新增客户”按钮。
- 不展示“编辑客户”或“删除客户”。
- 基础档案异常时引导用户在 ERP 核对。
- CRM 只提供在客户可用且有权限时的新建商机、拜访、跟进等关联业务动作；合同必须从商机详情发起，客户页仅提供跳转入口。
- `crmCustomerId` 是 CRM 快照内部标识，`erpCustomerId` 是跨系统关联主键；公司名称只用于展示/搜索，不作为关联键。
- 客户生命周期状态与快照同步处理状态分开展示；字段口径统一引用《客户字段清单》。
- 数据权限与《客户主PRD》一致。
- 表格最小宽度 1680px，窄屏横向滚动。

## 2. 风险 Tab 与计数

### 2.1 Tab 规格

| Tab | 过滤语义 | 计数来源 | 点击行为 |
|-----|----------|----------|----------|
| 全部客户 | 当前权限范围内全部客户快照 | 后台聚合 | 仅清除由 Tab 产生的风险条件，保留 AI 风险 Select、生命周期和同步筛选 |
| 高风险 | 最新成功结果为高风险 | 后台聚合 | 应用高风险过滤并回到第一页 |
| 中风险 | 最新成功结果为中风险 | 后台聚合 | 应用中风险过滤并回到第一页 |
| 低风险 | 最新成功结果为低风险 | 后台聚合 | 应用低风险过滤并回到第一页 |
| 待计算 | 尚无成功风险结果 | 后台聚合 | 展示待计算与失败不可用数据 |

### 2.2 计数规则

- 格式为 `Tab名称 (计数)`。
- 计数按当前用户数据范围聚合。
- 计数受其他查询条件影响。
- 计数不受分页影响。
- 风险计算完成后刷新各 Tab 计数。
- ERP 快照新增后刷新“全部客户”计数。
- 计数接口失败显示 `--`。
- 计数失败不阻断客户表格查询。
- 快速切换 Tab 时取消旧请求。
- 从详情返回时恢复原 Tab。

### 3.3 查询交互

- 公司名称输入按回车触发查询。
- 手机号格式错误时不发请求并就地提示。
- 风险 Tab、AI流失风险 Select、客户生命周期 Select 和 ERP同步标识默认取交集；任何一个条件变化都重新计算交集，不以后操作条件覆盖先前条件。
- 查询优先级为：数据权限 > 客户生命周期状态 > 风险 Tab 与 AI流失风险 Select > ERP同步标识 > 其他字段条件；无交集时展示空态。
- 查询中按钮展示加载图标。
- 查询失败保留上一批结果。
- 查询失败 Toast `客户查询失败，请重试`。
- 重置清空全部条件并回到“全部客户”。
- 重置不改变每页条数。

## 5. ERP 同步标识

### 5.1 定位

ERP 同步标识用于告诉用户 CRM 当前展示的快照是否为最近一次成功同步结果。它是同步任务元数据，不是可编辑客户字段，也不替代 ERP 客户状态。

生命周期与同步处理分离：客户生命周期仅展示 `PROSPECT/ACTIVE/DISABLED/MERGED`，同步处理仅展示 `PENDING_RECEIVE/VALIDATING/AVAILABLE/SYNC_FAILED`。`ERP已停用` 是生命周期 `DISABLED` 的提示，不是同步处理状态，也不是不可恢复的终态。

### 5.2 展示状态

| 标识文案 | 图标 | 视觉 | 说明 |
|----------|------|------|------|
| 已同步 | CheckCircle2 | 绿色 | 最近一次同步成功 |
| 同步中 | LoaderCircle | 蓝色旋转 | 正在处理新版本 |
| 同步异常 | AlertTriangle | 红色 | 最近一次处理失败，仍展示旧快照 |
| ERP已停用 | CircleSlash2 | 灰色 | 生命周期为 `DISABLED`，对新业务不可用但可由 ERP 启用事件恢复 |

### 5.3 交互

- 悬浮展示最后成功同步时间。
- 同步异常 Tooltip 展示用户可理解的错误摘要。
- 管理员在同步异常行的 More 菜单可执行“重试同步”。
- 销售仅可查看提示，不可重试。
- 点击“ERP已停用”跳转详情历史视图。
- 生命周期恢复只能由 ERP 合法启用事件触发；CRM 不展示“恢复客户”按钮。
- 不允许用户通过列表修改同步标识。
- 同步标识加载中保持列宽稳定。

### 5.4 跨模块引用与字段 SSOT

| 列表展示/关联对象 | 关联标识 | 权威字段清单 | 客户页权限 |
|--------------------|----------|--------------|------------|
| 商机 | CRM 内部 `crmCustomerId`；跨系统请求 `erpCustomerId` | 《商机字段清单》；客户基础字段引用《客户字段清单》 | 客户基础字段只读 |
| 合同 | CRM 内部 `crmCustomerId`；跨系统请求 `erpCustomerId` | 《合同字段清单》；客户基础字段引用《客户字段清单》 | 客户基础字段只读 |
| 拜访 | CRM 内部 `crmCustomerId`；跨系统请求 `erpCustomerId` | 《拜访管理/拜访计划字段清单》；客户基础字段引用《客户字段清单》 | 客户基础字段只读 |
| 跟进记录 | CRM 内部 `crmCustomerId`，保留来源对象标识 | 跟进记录对象字段 SSOT；客户基础字段引用《客户字段清单》 | 客户基础字段只读 |
| ERP 订单摘要 | `erpCustomerId` | ERP 订单接口契约/订单字段 SSOT | 只读，不在 CRM 编辑 |

列表页不重复定义商机、合同、拜访、跟进和订单字段；客户字段展示规则统一引用《客户字段清单》。所有跨系统请求必须携带 `erpCustomerId`，禁止用公司名称作关联键。

## 7. 行内操作

### 7.1 动作矩阵

| 客户快照场景 | 主操作 | More 菜单 |
|--------------|--------|-----------|
| `ACTIVE + AVAILABLE` | 查看 | 新建商机、跳转商机发起合同、添加跟进、创建拜访 |
| 高流失风险且可用 | 查看 | 添加跟进、新建商机、跳转商机发起合同、拜访 |
| `ACTIVE + PENDING_RECEIVE/VALIDATING` 且有最近成功快照 | 查看 | 允许关联动作，提交前重新校验；管理员可重试 |
| `ACTIVE + SYNC_FAILED` 且有最近成功快照 | 查看 | 允许关联动作，提交前重新校验；管理员可重试 |
| 无最近成功快照 | 查看待同步状态 | 不展示新关联业务动作；管理员可重试 |
| `DISABLED` ERP已停用 | 查看 | 无新业务动作；历史只读 |
| `MERGED` 已合并源客户 | 查看合并提示 | 无新业务动作；跳转主客户 |

### 7.2 动态规则

- 无权限动作不渲染。
- 不使用 disabled 灰色按钮代替。
- “新建商机”进入商机新增页并预填客户。
- “添加跟进”打开客户跟进抽屉。
- “创建拜访”进入拜访新增页并预填客户。
- 停用客户不展示新业务动作。
- 同步中或同步异常且有最近成功快照时，允许进入关联动作，但提交前必须重新校验 ERP 可用性、版本和事件标识。
- 没有最近成功快照时禁止新建关联业务，不使用临时编号或公司名称伪造关联。
- 停用客户统一不展示“添加跟进”，历史跟进仍可查；恢复后才重新开放。
- More 使用 Ellipsis 图标并有 Tooltip。
