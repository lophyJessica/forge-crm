## 需求描述：【拜访计划新增/编辑页】

> 来源：`拜访计划Demo_新增编辑页.md#1-页面布局`、`拜访计划主PRD.md#10.2-新增/编辑页`

### 页面内容
#### 页面模式
- 新增创建已计划拜访，编辑只允许修改未签到计划。
- 页头区分制定拜访计划和编辑计划，并提供返回列表。

### 交互说明
#### 进入
- 可从列表或关联对象详情进入；快捷入口可预填关联对象。
- 状态不在表单直接修改，签到和完成由详情/列表动作完成。

### 业务规则
#### 单据边界
- 一次拜访只关联一个对象；保存计划不执行签到。
- 已签到、已完成和已取消记录不可通过普通编辑覆盖。

### 字段说明
#### 页头
- 标题、来源说明、返回列表。

### 待确认
- 当前原型未实现来源提示条、负责人字段和状态只读摘要，待确认。

## 需求描述：【拜访计划表单】

> 来源：`拜访计划Demo_新增编辑页.md#2-表单字段`、`拜访计划字段清单.md#2.计划字段`、`拜访计划字段清单.md#5.关联字段`、`拜访计划主PRD.md#4.4-时间和空值规则`、`拜访计划主PRD.md#6-关联对象规则`

### 页面内容
#### 字段分组
- 基本信息卡片承载关联对象、拜访标题、拜访方式、计划时间、负责人和地址。
- 表单区展示必填标识和字段错误。

### 交互说明
- 选择关联类型后加载对应的线索、商机或正式客户候选；切换类型时清空旧对象。
- 选择关联对象后可生成标题建议，手工输入不被覆盖；拜访方式变化时调整地址提示。
- 计划时间、结束时间和地址错误在字段下方提示；编辑已锁定计划时关联对象不可更换。

### 业务规则
#### 关联与时间
- 关联类型与对象 ID 必须成对且使用稳定 ID；只返回用户可见对象，名称和状态只作快照。
- 已转客户线索、终态商机和停用客户不作为新计划候选；关联商机可继承客户快照。
- 结束时间必须晚于开始时间；新建计划时间不得早于当前业务时间。
- 上门拜访地址条件必填，电话和视频方式的地址可填写链接或号码。
- 状态、签到时间和完成时间均为系统或动作写入，不是可编辑字段。

### 字段说明
| 字段 | 展示/输入类型 | 业务说明 | 约束与备注 |
| --- | --- | --- | --- |
| 关联对象类型 | Select | 计划关联的业务对象类型。 | 必填；`LEAD`=线索、`OPPORTUNITY`=商机、`CUSTOMER`=正式客户。 |
| 关联对象ID | Select | 计划关联对象的稳定编码。 | 必填；保存唯一 ID，不以名称作为关联键。 |
| 拜访标题 | Input | 拜访计划主题。 | 必填；文本，最多 100 字符。 |
| 拜访方式 | Select | 沟通方式。 | 必填；上门、电话、视频。 |
| 计划拜访时间 | DateTimeInput | 计划开始时间。 | 必填；`YYYY-MM-DD HH:mm`，新建不得早于当前业务时间。 |
| 计划结束时间 | DateTimeInput | 计划结束时间。 | 必填；必须晚于开始时间。 |
| 负责人 | 只读文本 | 当前计划负责人。 | 系统带出当前销售，不提供用户直接修改。 |
| 拜访地址 | Input | 上门现场地址、视频链接或电话号码。 | 上门时条件必填；长度与清洗规则以字段清单为准。 |

### 待确认
- 当前原型使用本地 Select，未实现远程搜索、防抖、候选权限和对象更换确认；状态/执行结果只读区也未在本页展示，待确认。

## 需求描述：【拜访计划底部操作栏】

> 来源：`拜访计划Demo_新增编辑页.md#1-页面布局`、`拜访计划Demo_新增编辑页.md#3-新增流程`

### 页面内容
#### 操作按钮
- 固定底栏提供返回列表和保存计划。

### 交互说明
#### 保存与离开
- 保存期间按钮禁用；失败保留输入并可重试。
- 有未保存变更时离开应提示确认。

### 业务规则
#### 状态生成
- 新建成功固定生成 `PLANNED + NOT_STARTED`；保存计划不签到。
- 编辑保存不改变状态。

### 字段说明
#### 操作字段
- 返回列表、保存计划、loading、错误提示和 Toast。

### 待确认
- 当前原型未实现保存草稿/创建计划区分和未保存离开确认，待确认。

## 需求描述：【保存拜访计划】

> 来源：`拜访计划Demo_新增编辑页.md#3-新增流程`、`拜访计划Demo_新增编辑页.md#5-校验与错误状态`、`拜访计划主PRD.md#9-状态动作权限与失败处理矩阵`

### 页面内容
#### 提交
- 点击保存计划提交表单，成功后提示保存成功并回到拜访列表。

### 交互说明
#### 校验与反馈
- 必填字段、对象稳定 ID、时间和客户状态校验失败时阻断保存。
- 网络或 Mock 失败时保留输入和幂等键，支持安全重试。

### 业务规则
#### 客户状态
- ACTIVE 且同步可用允许创建；同步中或失败需提交前重新校验；客户停用阻断新建。
- 不生成半条计划，状态写入需完整。

### 字段说明
#### 写入字段
- 关联 ID 和名称/状态快照、计划字段、负责人、幂等标识和审计信息。

### 待确认
- 当前原型使用本地数据库直接保存，未实现服务端权限、幂等、版本和 ERP 状态校验，待确认。
