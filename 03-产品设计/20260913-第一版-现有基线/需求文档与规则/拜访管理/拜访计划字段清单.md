# 拜访计划字段清单

> **版本**：V2.0 | 2026-08-13
> **对象**：`VisitPlan` | **端**：PC Web | **时间基准**：`Asia/Shanghai`

## 1. 字段约定

- 字段名、组件名、枚举值保留英文；页面标签使用简体中文。
- 状态和执行事实由动作按钮写入，表单不可直接编辑 `primaryStatus`、`executionResult`、`checkInAt`、`completedAt`。
- 关联使用稳定 ID；名称和状态仅为快照展示，禁止以名称作为关联键。
- “系统自动”表示由服务端或动作接口生成；“动作必填”表示必须通过对应按钮提交。
- 所有时间存储为带时区 ISO 时间，页面统一显示 `YYYY-MM-DD HH:mm`；空值统一显示 `—`。

| `rescheduledAt` | 改期时间 | DateTime（只读） | 服务端生成；未改期显示 `—` | 改期动作 | 条件自动 | 详情/审计 |
| `cancelledAt` | 取消时间 | DateTime（只读） | 服务端生成；未取消显示 `—` | 取消动作 | 条件自动 | 详情/审计 |

客户关联状态口径：生命周期只接受《客户字段清单》的 `ACTIVE` / `DISABLED`；同步处理只接受 `PENDING_RECEIVE` / `VALIDATING` / `AVAILABLE` / `SYNC_FAILED`。`DISABLED` 阻断新建、改期新单和新签到；已签到拜访可完成并生成跟进，这是历史执行事实收口，不是新增业务。

## 7. 状态 Tag 配色登记

| 状态/结果 | 页面文案 | 配色 | 使用规则 |
|---|---|---|---|
| `PLANNED` | 已计划 | 蓝色 `#1677FF` | 计划未执行的主状态。 |
| `CHECKED_IN` | 已签到 | 橙色 `#FA8C16` | 已有服务端签到事实。 |
| `COMPLETED` | 已完成 | 绿色 `#52C41A` | 已提交反馈并完成收口。 |
| `CANCELLED` | 已取消 | 红色 `#F5222D` | 计划终止；已签到时叠加“已签到后取消”。 |
| `NOT_STARTED` | 未开始 | 灰蓝色 `#597EF7` | `executionResult` 默认值；与 PLANNED 同时展示。 |
| `MISSED` | 未到访 | 紫色 `#722ED1` | 仅由“标记未到访”动作写入。 |
| `RESCHEDULED` | 已改期 | 灰色 `#8C8C8C` | 原拜访标记；新拜访回到 NOT_STARTED。 |
| `CHECK_IN_FAILED` | 签到失败 | 黄色 `#FAAD14` | 异常标识，不改变主状态；可重试。 |
| `CUSTOMER_NO_SHOW` | 客户未出现 | 紫色 `#9254DE` | 反馈结果/异常标识，不覆盖签到事实。 |
| `OVERTIME` | 超时 | 黄色 `#FAAD14` | 计算或异常提示；不自动改变主状态。 |
| `RETURNED` | 反馈退回 | 黄色 `#FAAD14` | 反馈审核状态；等待补充后重新提交。 |
| `FOLLOW_UP_PENDING` | 跟进待生成 | 黄色 `#FAAD14` | 跟进接口失败；使用幂等键重试。 |
| `DRAFT` | 反馈草稿 | 灰色 `#8C8C8C` | CHECKED_IN 时已保存但未完成的反馈。 |
| `PENDING` | 待审核 | 蓝色 `#1677FF` | 完成后等待主管审核（如启用审核）。 |
| `ACCEPTED` | 已接受 | 绿色 `#52C41A` | 反馈审核通过；不改变主状态。 |
| `NOT_REQUIRED` | 无需审核 | 灰色 `#BFBFBF` | 当前流程不要求主管审核。 |

## 8. 关键字段联动与空值规则

| 场景 | 字段结果 |
|---|---|
| 新建 | `primaryStatus=PLANNED`、`executionResult=NOT_STARTED`、`checkInAt=NULL`、`completedAt=NULL`。 |
| 未签到取消 | `primaryStatus=CANCELLED`、`checkInAt=NULL`、`cancelReason` 有值。 |
| 已签到后取消 | `primaryStatus=CANCELLED`、`checkInAt`/定位保留、`cancelReason` 有值、时间线写明已签到后取消。 |
| 正常完成 | `primaryStatus=COMPLETED`、`checkInAt`/`completedAt` 有值、反馈必填字段落库。 |
| 完成后无下一步 | `followUpRecordId=NULL`、`followUpCreateSkippedReason=NO_NEXT_ACTION`。 |
| 完成后跟进失败 | `primaryStatus=COMPLETED`、`executionException=FOLLOW_UP_PENDING`、幂等重试可用。 |
| 任何失败 | 原状态和已存在事实不被覆盖；写 `operationId`、失败原因和 `auditLogId`。 |
