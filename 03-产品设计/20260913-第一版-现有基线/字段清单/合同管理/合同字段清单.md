# 合同字段清单

> **版本**：V1.2 | 2026-08-13
> **定位**：合同业务记录与跨系统结果字段 SSOT；合同仅保存签约控制摘要，不保存完整条款、附件或真实签章凭证。

## 一、基础字段

| 字段名称 | 字段来源 | 取值说明 | 必填性 | 列表展示 | 可筛选 | 详情展示 |
|----------|---------|---------|:------:|:------:|:------:|:------:|
| 合同编号 | 系统生成 | `CT{YYYYMMDD}-{4位序号}` | 系统自动 | 是(168px) | 是(Input) | 是 |
| 合同名称 | 用户填写 | 文本,上限100字符 | 必填 | 是(200px) | 是(Input) | 是 |
| 关联客户 | 系统带出 | 从商机继承 | 必填 | 是(160px) | 是(Select) | 是 |
| 关联商机 | 系统带出 | 商机编号 | 必填 | 是(160px) | 否 | 是 |
| 合同金额 | 用户填写 | 金额数值，2位小数；必须同时记录币种、含税标识和税率 | 必填 | 是(140px) | 否 | 是 |
| 合同状态 | 系统生成 | DRAFT/PENDING_SIGN/SIGNED/ARCHIVED/VOIDED | 系统自动 | 是(100px) | 是(Select) | 是 |
| 签署日期 | 系统生成 | 外部 `signedAt` 转展示日期；不是 CRM 接收时间 | 系统自动 | 是(140px) | 是(DateRange) | 是 |

## 七、系统字段

创建人/创建时间/最后修改时间按标准模板定义。

## 八、展示与时间口径规则

- `signedAt` = 外部平台真实签署时间；`receivedAt` = CRM 接收事件时间；`mockedAt` = CRM Mock 操作时间，三者不可互相覆盖。
- 作废原因、作废时间、归档人、归档时间、归档结果、签署结果和联动结果均以本清单为展示 SSOT。
- 状态 Tag 配色：`DRAFT` 灰色、`PENDING_SIGN` 蓝色、`SIGNED` 绿色、`ARCHIVED` 深绿色、`VOIDED` 红色；联动失败使用橙色警示，配合文字，不以颜色作为唯一表达。
