# 业绩目标字段清单

> **版本**：V2.1 | 2026-08-13
> **字段 SSOT 说明**：本清单统一定义字段名称、来源、格式、范围、精度、状态枚举和只读边界；Demo 仅引用本清单，不重复定义校验。

## 一、基础字段

| 字段名称 | 字段来源 | 必填性 | 列表展示 |
|----------|---------|:------:|:------:|
| 目标编号 | 系统生成 `TGT{YYYYMM}-{销售ID}` | 系统自动 | 是 |
| 销售 | 用户填写，保存销售ID | 必填 | 是 |
| 目标月份 | 用户填写 `YYYY-MM` | 必填 | 是 |
| 线索目标数 | 用户填写 | 必填 | 是 |
| 商机目标数 | 用户填写 | 必填 | 是 |
| 赢单目标金额 | 用户填写 | 必填 | 是 |
| 目标创建时间 | 系统生成 | 系统自动 | 否 |
| 创建人 | 系统生成 | 系统自动 | 否 |
| 目标状态 | 系统生成 ACTIVE/ACHIEVED/UNACHIEVED | 系统自动 | 是 |

基础约束：目标对象粒度为 `销售ID + 目标月份`，同一销售同一月份最多一条；目标状态只能由创建成功或月末结算动作产生，表单不提供状态编辑。

## 二、销售归属字段

| 字段名称 | 字段来源 | 必填性 | 列表展示 |
|----------|---------|:------:|:------:|
| 销售ID | 销售主数据映射 | 必填 | 是 |
| 销售姓名快照 | 创建/调整时销售主数据 | 系统自动 | 是 |
| 团队快照 | 创建/结算时销售主数据 | 系统自动 | 否；详情可见 |
| 区域快照 | 创建/结算时销售主数据 | 系统自动 | 否；详情可见 |
| 当前销售姓名 | 销售主数据实时读取 | 系统自动 | 可选 |

归属约束：一期统计维度只有 `销售ID + 目标月份`；团队是权限范围，主管按团队查看，不是统计维度，也不生成独立团队目标。销售转组后历史目标保留原团队快照；销售改名不改变销售ID和历史归属。

## 六、结算任务异常字段

| 字段名称 | 字段来源 | 必填性 | 列表展示 |
|----------|---------|:------:|:------:|
| 结算处理状态 | 系统生成 `NOT_STARTED/PROCESSING/SUCCESS/FAILED/RETRYING` | 系统自动 | 是 |
| 失败原因 | 结算任务错误 | FAILED 时必填 | Tooltip/详情 |
| 结算任务编号 | 结算调度生成 | 结算启动时必填 | 详情可见 |
| 截止时间 | 结算任务生成 | 必填 | 详情可见 |
| 最近结算时间 | 最近一次尝试时间 | 系统自动 | 是 |
| 重试次数 | 结算任务累计 | 系统自动 | 详情可见 |
| 补偿状态 | `NOT_REQUIRED/PENDING/RUNNING/COMPLETED` | 系统自动 | 是 |
| 结算幂等键 | `目标编号 + 目标月份` | 系统生成 | 否 |

双状态约束：`目标状态`与`结算处理状态`分开存储。`PROCESSING/RETRYING` 的页面标签为“结算中”，`FAILED` 的页面标签为“结算异常”；结算异常不是目标终态，目标主状态仍为 ACTIVE。`SUCCESS` 后才允许目标状态进入 ACHIEVED 或 UNACHIEVED。

## 九、数值范围与精度规则

| 字段 | 最小值 | 最大值 | 精度/输入规则 | 零值处理 |
|------|--------|--------|---------------|----------|
| 线索目标数 | 0 | 999,999 | 非负整数；禁止小数、负数、科学计数法 | 0 表示本月不要求该指标，当前值≥0 即该项达标，达成率显示 100% |
| 商机目标数 | 0 | 999,999 | 非负整数；禁止小数、负数、科学计数法 | 同上 |
| 赢单目标金额 | 0.00 CNY | 999,999,999.99 CNY | 非负，最多 2 位小数；禁止科学计数法 | 0 表示本月不要求金额，ERP 确认订单金额≥0 即该项达标，达成率显示 100% |
| 当前进度金额 | 0.00 CNY | 按来源金额上限 | 计算值保留 2 位小数 | 不做除零，按目标为 0 的规则处理 |

保存规则：超出最大值、负数、小数位超限、科学计数法、非 CNY 或格式非法均阻断保存；当前值已超过新目标允许保存，显示真实超过 100% 的达成率，不回写事件、不提前改变目标状态。

## 十、状态 Tag 与进度条配色

| 标签 | 对应字段/条件 | 颜色 | 辅助表达 |
|------|---------------|------|----------|
| `ACTIVE` 进行中 | 目标状态=ACTIVE 且结算处理状态=NOT_STARTED | 蓝色 `#1677FF` | Play/进行中文本 |
| `ACHIEVED` 已达成 | 目标状态=ACHIEVED 且结算处理状态=SUCCESS | 绿色 `#52C41A` | CheckCircle/已达成文本 |
| `UNACHIEVED` 未达成 | 目标状态=UNACHIEVED 且结算处理状态=SUCCESS | 红色 `#FF4D4F` | CloseCircle/未达成文本 |
| `结算中` | 结算处理状态=PROCESSING 或 RETRYING | 橙色 `#FA8C16` | Loader/结算中文本 |
| `结算异常` | 结算处理状态=FAILED | 红色 `#FF4D4F` | Warning/结算异常文本 |

颜色不是唯一表达，必须同时显示文字或图标；`结算中/结算异常`是处理状态标签，不得覆盖目标主状态。
