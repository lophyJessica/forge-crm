# 公海字段清单

> **说明**：公海是线索的子视图，字段来自《线索字段清单》。本文件仅列出公海视图独有的展示规则。
> **版本**：V1.0 | 2026-07-18

---

## 一、公海视图列表列

继承线索字段清单中 `列表展示=是` 的字段，并额外展示：

| 字段名称 | 字段来源 | 列表展示 | 说明 |
|----------|---------|:------:|------|
| 线索编号 | 继承线索 | 是 | |
| 公司名称 | 继承线索 | 是 | |
| 线索来源 | 继承线索 | 是 | |
| 所属行业 | 继承线索 | 是 | |
| AI评分 | 继承线索 | 是 | |
| 入池时间 | 系统计算 | 是 | `PENDING_ASSIGN` 待分配池取进入池时间；主动放弃取 `abandonAt`；展示规则引用《线索字段清单》 |
| `poolType` | 继承线索 | 是 | `ASSIGN_POOL`待分配池 / `NURTURE_POOL`培育池；页面分组字段，不改变统一状态 |
| `voidType` | 继承线索 | 按权限 | `VOLUNTARY_ABANDON`主动放弃 / `MANAGER_VOID`管理作废 / `DRAFT_VOID`作废草稿 |
| 放弃原因 | 继承线索 | 是 | 主动放弃按字段清单至少 15 字；管理作废按管理权限校验 |
| 操作 | — | 是 | 认领按钮 |

## 二、池子与公海可见性标签

| 字段/类型 | 标签文案 | 颜色 |
|----------|---------|------|
| `ASSIGN_POOL` | 待分配池 | 蓝色（`PENDING_ASSIGN`，普通销售可认领） |
| `NURTURE_POOL` | 培育池 | 紫色（低于 50 分默认进入，普通销售不可直接认领） |
| `VOLUNTARY_ABANDON` | 主动放弃 | 灰色（满 7 天后按权限进入公海） |
| `MANAGER_VOID` / `DRAFT_VOID` | 管理作废 / 作废草稿 | 深灰（普通销售不可见、不可认领） |

---

## 三、排序规则

- 默认排序:AI评分倒序(高分线索优先)
- 普通销售可见条件为 `PENDING_ASSIGN + ASSIGN_POOL`，或 `ABANDONED + VOLUNTARY_ABANDON + abandonAt` 满 7 天；原销售保护期内可见但其他销售不可见。
- 主管/管理员可按权限查看全部池子与作废记录；培育池需通过管理动作分配，不提供普通销售直接认领。
- 认领后从普通公海移除；任何作废/放弃均通过动作按钮触发，字段清单为枚举和必填 SSOT。
