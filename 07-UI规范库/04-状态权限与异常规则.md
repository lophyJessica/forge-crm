# 04 · 状态权限与异常规则

> **定位**：Forge-CRM 页面的空态 / 加载 / 错误 / 权限 / 危险动作的统一表现。状态含义以业务PRD为准，此处只规范**展示**。

## 一、Loading
- 列表/表单首次加载：`Skeleton`（组件库有）占位。
- 提交中：按钮禁用 + 文案（"提交中…"）；不得重复提交。

## 二、Empty（空态）
- 列表无结果：表格内空态提示"暂无数据"；筛选无命中：提示"当前筛选条件下没有结果"。
- 表单/详情无关联数据：占位文案（"—" 或 "暂无记录"），不造空壳样式。

## 三、Error 与异常反馈
- 操作失败：toast/dialog 提示，保留原状（数据不变，状态不跳转）。
- 竞争失败（认领/转客户被他人处理）：提示"数据已被其他用户处理，请刷新列表"并刷新。
- ERP 同步失败：保留线索原状态，提示稍后重试；不丢失已录内容。

## 四、权限/数据范围
- 按钮显隐按角色 + 负责人 + 状态（来自业务PRD 状态-操作矩阵 + 权限规则）。
- 数据范围：列表/筛选/分页遵循当前用户数据权限（管理员全量/销售本人+规则公海/主管团队）。
- 无权限动作：不渲染按钮（不是禁用后仍显示）。
- 导出/批量分配：按角色权限限定范围。

## 五、危险动作（全站统一）
| 动作 | 触发 | 确认弹窗 | 后果说明 |
| --- | --- | --- | --- |
| 删除（未生效） | 物理删除 | 必弹 | 永久移除不可恢复 |
| 作废/取消（未生效） | 状态变更 | 必弹 | 进入已作废/已取消 |
| 放弃线索 | 状态变更 | 必弹 | 放弃原因至少15字 |
| 转客户 | 确认 | 必弹 | 成功后同步ERP客户档案 |
| 批量作废 | 批量 | 必弹 | 列出将影响条数 |

- 可逆动作（保存草稿/取消选择）不弹确认。
- 状态变更一律走业务动作，不做"直接改状态"入口。

## 六、Success
- 提交/操作成功：toast 确认 + 页面状态更新（列表刷新、状态 Badge 变化、数量计数同步）。

## 七、与下游的一致
状态展示、空态/错误/权限表现更新 → 改本文件 + 对应 Demo PRD + 原型；不变更字段TSV/业务PRD（除非涉及业务事实）。
