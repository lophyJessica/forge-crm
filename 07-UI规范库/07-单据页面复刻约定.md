# 07 · 单据页面复刻约定

> **定位**：Forge-CRM 单据类页面（新增/编辑 + 详情）的区划分层与复刻约定。适用于线索/商机/合同/拜访/业绩目标等有"表单/详情"的模块。

## 一、表单页（create/edit 共用）
分区：
```
页面头部：标题「新建X/编辑X」+ 面包屑
基本信息区（Card）：主对象字段
  线索/商机：来源/行业/联系人/手机号/邮箱/公司
  关联区：公司/客户/所属
明细区（单据类）：若有多行明细子表
底部操作区：fixed bottom（保存草稿 / 提交 / 取消）
```
约定：
- 字段分组用 `###底层`（Card + grid-cols-* 响应式降列）。
- 提交校验：失焦格式 + 提交全量；错误定位到字段/明细行。
- 底部操作 `fixed bottom-0 z-40 bg-white border-t`（对齐 ContractForm）。
- 新增/编辑共用一页：路由共用，模式区分（`?edit=` / id 有无）。

## 二、详情页
分区：
```
页头：标题 + 状态Badge + 操作按钮（编辑/跟进/转客户/放弃…按 状态-操作矩阵）
基本信息区（只读字段）
业务区：跟进记录 / 关联明细（线索→商机/合同/拜访）
制单信息：创建人/创建时间/最后修改
```
约定：
- 只读展示为主；操作按钮来自业务PRD 状态-操作矩阵。
- 关联区承载跨对象关系；ERP 联动结果（已转客户等）在此展示后续链接。

## 三、复刻铁律
- 页面结构严格按 02 模板；字段来自字段清单TSV；操作来自状态-操作矩阵；校验/反馈按 Demo PRD。
- 不反向从页面发明字段/状态/按钮。
- 复刻/改版时保留 `data-anno` 锚点 + Dexie/erpSync 契约 + 路由。
