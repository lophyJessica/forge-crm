# 08 · 轻量配置与弹窗表单约定

> **定位**：Forge-CRM 弹窗（Dialog）、抽屉、轻量配置表单（如新建时的快捷录入、批量操作确认、待确认问题表单）的标准。

## 一、Dialog（确认/快捷表单）
- 结构：标题区（+ 关闭×）+ 内容区 + 底部操作区。
- 确认类：标题 + 正文要点 + 危险确认按钮（destructive）+ 取消；正文写明不可逆后果。
- 快捷录入表单：字段紧凑（sm 尺寸/h-8），校验失焦+提交，错误定位字段。
- 关闭：有未保存内容需二次确认。

## 二、批量操作确认
- 批量作废/批量分配：弹窗列出"将影响 N 条" + 明确后果；确认才执行。
- 竞态：弹窗触发后校验数据是否仍有效（如已被他人处理则提示刷新）。

## 三、轻量配置（如数据字典/设置类）
- 结构简洁：字段少、无需完整详情页时用弹窗/抽屉承载。
- 标签+轻表单，不做重页面。

## 四、与全局一致
- 颜色/按钮用 01/03；权限/异常表现用 04；字段来自 TSV；动作来自业务PRD。
