# 03 · 组件与交互规则

> **定位**：Forge-CRM 使用的 shadcn 组件（`src/components/ui/`）的用法、状态、校验、浮层交互统一约定。
> **组件清单**（src/components/ui/）：alert / badge / button / card / dialog / dropdown-menu / input / label / select / separator / skeleton / table / tabs / textarea。

## 一、Button
- 变体：`default`（蓝主操作）/ `secondary`（slate次要）/ `outline`（描边）/ `ghost`（幽灵）/ `destructive`（红危险）/ `link`。
- 主操作每页 1 个主色；次要操作用 secondary/outline；危险操作 destructive（需确认）。
- 尺寸：default `h-9` / sm `h-8 text-xs` / icon `h-9 w-9`。
- `disabled:opacity-50 disabled:pointer-events-none`；带图标时 `[&_svg]:size-4`。

## 二、Input / Textarea / Select
- Input/Select 默认 `h-9 text-xs`；`aria-label` 必备（可访问）。
- 校验时机与反馈按字段清单约束 + Demo PRD，不在组件层硬编码业务规则。
- 过滤搜索、负责人下拉等 Select 支持 `clearable` / 可搜索时按需。

## 三、Table（列表）
- `Card className="overflow-hidden"` 外套；`TableHeader/TableBody/TableRow/TableHead/TableCell`。
- 行操作列固定右侧（可横向滚动）；Checkbox 列宽度固定（`w-12`）。
- 数量类列右对齐（`text-right`）。
- 状态本列/标签用 `Badge`。

## 四、Badge（状态）
- 展示中文业务状态名（待分配/跟进中/已转客户…），英文枚举（PENDING_ASSIGN）仅辅助/不展示。
- 颜色语义：进行中=蓝、成功=绿、异常=红、停用/作废=灰（与 `04` 状态规则一致）。

## 五、Tabs
- 状态/模块页签用 Tabs；数量徽标（如各状态计数）随状态变化同步。
- 选中态高亮用 primary。

## 六、Dialog / DropdownMenu
- 确认类弹窗：标题 + 正文要点 + 危险确认按钮（destructive）+ 取消。
- 二次确认：删除/作废/取消/转客户等，弹窗正文写明不可逆后果。
- DropdownMenu 行操作"更多"收纳次要动作。

## 七、通用交互铁律
- **状态不是表单字段**：不能让用户在下拉直接改状态；状态必须由业务动作触发（审核/确认/放弃/转客户…），每动作弹二次确认。
- 危险动作（删除/作废/取消/批量）一律二次确认；不可逆动作弹窗正文写清后果。
- 校验：失焦校验格式 + 提交全量校验，错误定位到对应字段/明细行。
- 浮层（Dialog/Drawer）：标题区 + 内容 + 底部操作，关闭需二次确认（若有未保存）。

## 八、变化规则
新增/调整组件用法 → 更新本文件；不改业务PRD与字段清单。
