# 拜访计划 Demo：新增/编辑页

> **版本**：V2.0 | 2026-08-13  
> **页面路由**：`/crm/visits/new`、`/crm/visits/:visitId/edit`  
> **页面目标**：维护计划信息，不提供直接修改状态的表单控件。

## 2. 表单字段

| 区域 | 字段/组件 | 交互规则 |
|---|---|---|
| 基础信息 | `title` Input | 必填，≤100 字符；保存时去除首尾空格。 |
| 基础信息 | `visitMethod` Radio | `ONSITE`、`PHONE`、`VIDEO`；切换为电话/视频时地址改为选填。 |
| 关联信息 | `relatedObjectType` Select | 选择后按类型查询对象；显示名称和 ID；不允许仅输名称提交。 |
| 关联信息 | `relatedObjectId` ObjectSelect | 必须从可访问对象中选择稳定 ID；同时回填名称和状态快照。 |
| 关联信息 | `relatedObjectNameSnapshot` Text（只读） | 仅展示快照，不允许用户手工作为关联键写入。 |
| 关联信息 | `inheritedCustomerId` Link（只读） | 关联 `OPPORTUNITY` 时展示商机继承客户；客户状态供校验。 |
| 负责人 | `assigneeId` UserSelect | 当前销售默认本人；主管可选择团队成员；无权限用户不可选。 |
| 时间 | `plannedStartAt` / `plannedEndAt` DateTimePicker | 使用 `Asia/Shanghai`；结束时间必须晚于开始时间。 |
| 地址 | `address` Textarea | `ONSITE` 建议填写；≤255 字符；不做地图/路线能力。 |
| 系统信息 | `primaryStatus` / `executionResult` StatusTag | 只读：新增固定 `PLANNED + NOT_STARTED`，编辑只展示当前值。 |
| 系统信息 | `checkInAt` / `completedAt` DateTime | 只读；空值显示 `—`；编辑页不提供手工签到/完成。 |

## 3. 新增流程

1. 用户填写计划字段并点击“创建计划”，弹出二次确认摘要：标题、关联对象、负责人、计划时间。
2. 提交前服务端校验：权限、时间、对象稳定 ID、ERP 客户状态、对象访问权和版本。
3. 客户生命周期 `ACTIVE` 且同步 `AVAILABLE` 允许创建；同步 `PENDING_RECEIVE`/`VALIDATING`/`SYNC_FAILED` 仅允许草稿暂存，正式创建按钮必须完成提交前校验；生命周期 `DISABLED` 阻断并提示“客户已停用，无法创建新拜访”。
4. 成功落库 `primaryStatus=PLANNED`、`executionResult=NOT_STARTED`、关联 ID/名称快照/状态快照、`idempotencyKey` 和审计日志，Toast“拜访计划已创建”，跳转详情。
5. 网络或 Mock 失败：停留当前页，保留输入，Toast 显示具体原因并提供重试；不生成半条计划。

## 4. 编辑流程

- 仅 `PLANNED + NOT_STARTED` 且未签到、未取消的计划可由负责人编辑计划字段；主管/管理员可编辑团队计划。
- 编辑不提供状态 Select；状态变化必须回到详情/列表点击动作按钮。
- 修改关联对象需主管/管理员点击独立动作“更换关联对象”，填写原因，并在详情审计中保留前后 ID 与快照；普通编辑页不允许静默更换。
- 已超时但未签到的计划仍可修改非事实字段，但不能通过编辑页直接设置 `MISSED`；必须点击“标记未到访”。
- `CHECKED_IN`、`COMPLETED`、`CANCELLED` 或 `MISSED` 原单不可通过编辑页覆盖时间；改期/重新计划使用动作生成新单。
- `COMPLETED` 销售进入编辑路由时展示只读详情并提示“已完成拜访默认只读”；主管/管理员使用“补充反馈”弹窗，不修改计划事实。

## 5. 校验与错误状态

| 场景 | 校验/提示 |
|---|---|
| 标题为空 | “请输入拜访标题”。 |
| 关联对象缺失 | “请选择关联对象；关联必须使用稳定 ID”。 |
| 关联对象只填名称 | “请从对象选择器中选择记录，不能使用名称直接关联”。 |
| 结束早于开始 | “计划结束时间必须晚于开始时间”。 |
| 客户停用 | “客户已停用，无法新建拜访；历史记录可在详情查看”。 |
| ERP 同步中/失败 | “客户状态待 ERP 校验，提交前将重新校验”；校验失败时阻断并支持重试。 |
| 版本冲突 | “记录已被其他人更新，请刷新后重试”；不覆盖他人修改。 |
| 无编辑权限 | “当前角色无编辑权限”；隐藏保存按钮。 |
| 接口/网络失败 | “保存失败，请重试”；输入不丢失，幂等键不变。 |

## 6. 页面验收

| 编号 | Given | When | Then |
|---|---|---|---|
| N01 | 新建页 | 不选择对象直接提交 | 阻断；状态不生成；提示选择稳定 ID。 |
| N02 | 新建页 | 选择 ACTIVE 客户并提交 | 生成 `PLANNED + NOT_STARTED`，写入 ID 和快照。 |
| N03 | 新建页 | 选择 `DISABLED` 客户并提交 | 阻断；无拜访记录落库。 |
| N04 | 编辑页 | 销售尝试修改状态 | 页面没有可编辑状态控件；状态只能由动作按钮改变。 |
| N05 | 已签到记录 | 打开编辑路由 | 计划事实只读；提供返回详情/填写反馈入口。 |
| N06 | 已完成记录 | 销售打开编辑路由 | 全部只读；主管/管理员可从详情进入补充反馈。 |
