# 线索_Demo_列表页

> **文档定位**：AI 生成线索列表页前端原型的输入文档，聚焦页面结构、控件类型、交互行为。
> **字段定义**：字段名称、枚举值、必填性、类型和校验规则见《线索字段清单》，本文件只写页面呈现规则，严禁重复定义。
> **版本**：V1.2 | 2026-08-13

## 1. 页面概述

| 项目 | 内容 |
|------|------|
| 页面名称 | 线索池 |
| 页面目标 | 帮助销售查看自己名下的线索，或从公海认领新线索 |
| 页面路径 | `/leads` |
| 骨架结构 | 顶部 Tab 栏 + 查询卡片 + 工具条 + 表格卡片 |

## 2. 状态 Tab 栏

| Tab 标签 | 过滤逻辑 |
|----------|---------|
| 全部 | 展示所有状态（默认选中） |
| 待分配 | `PENDING_ASSIGN`；通过字段清单定义的 `poolType` 展示待分配池与培育池分组 |
| 我的线索 | DRAFT + ASSIGNED + FOLLOWING（当前登录销售创建或归属名下的进行中线索） |
| 公海 | `PENDING_ASSIGN + poolType=ASSIGN_POOL`；`voidType=VOLUNTARY_ABANDON` 的已作废线索由原负责人立即可见并可撤销放弃，其他销售在已作废超过7天后可见并认领 |
| 已转客户 | CONVERTED |
| 已作废 | ABANDONED |

**Tab 交互规则**：
- 每个 Tab 右侧展示计数（格式：`Tab名 N`，超过 99 展示 `99+`）
- 切换 Tab 后列表刷新，页码重置，不清空查询条件
- 「我的线索」Tab 仅对销售角色可见

## 3. 查询区

### 布局

桌面端 6 列栅格。筛选条件先在查询区暂存，点击「搜索」后刷新列表；高级筛选可展开/收起，右侧提供「重置」操作。

### 查询条件

| 字段 | 控件类型 | 规格说明 |
|------|---------|---------|
| 关键词 | Input | 支持逗号或换行分隔多个关键词；任一关键词命中线索编号、公司名称、联系人或手机号即匹配 |
| 线索来源 | Select | 选项及枚举文案引用《线索字段清单》，本页不重复定义 |
| 所属行业 | Select | 选项及枚举文案引用《线索字段清单》，本页不重复定义 |
| AI评分 | Range | 控件取值范围及字段定义引用《线索字段清单》；**页面交互规则**：最小值不得大于最大值，错误时阻断搜索并提示“最小评分不能大于最大评分” |
| 业务池 | Select | 选项及枚举文案引用《线索字段清单》的 `poolType`；用于区分待分配池与培育池，不改变 `线索状态` |
| 归属人 | SelectWithSearch | 销售列表，搜索姓名 |
| 创建时间 | DateRange | 字段定义引用《线索字段清单》；**页面交互规则**：支持快捷选项今天/本周/本月，以及自定义开始日期-结束日期 |

### 查询操作

- **搜索**：点击后按当前页签、关键词、来源、行业、AI评分、业务池、负责人和创建时间条件查询，并将页码重置为第1页。
- **高级筛选**：点击「展开/收起高级筛选」显示或隐藏 AI评分、负责人、创建时间等高级条件，不清空已输入条件。
- **重置**：清空关键词、来源、行业、AI评分、业务池、负责人、创建时间和其他高级筛选条件，并恢复默认列表。
- **关键词匹配**：多个关键词使用逗号或换行分隔，匹配公司名称、联系人、手机号和线索编号，任一关键词命中即保留。
- **评分校验（页面交互规则）**：按《线索字段清单》的 `AI评分` 定义校验范围；最小值≤最大值时才发起查询。
- **创建时间（页面交互规则）**：按《线索字段清单》执行筛选；快捷选项转换为对应日期区间，自定义区间要求开始日期不晚于结束日期。

## 5. 表格

### 表格行为

| 行为 | 规格 |
|------|------|
| 行勾选 | 支持（批量分配、批量作废时使用） |
| 批量分配 | 支持勾选后批量分配给销售，仅销售主管权限可用；状态、权限及字段规则引用主PRD/字段清单 |
| 批量作废 | 支持勾选后由销售主管或系统管理员发起；仅处理 `PENDING_ASSIGN`、`ASSIGNED`、`FOLLOWING`，统一填写符合字段清单的放弃原因；逐条返回成功/失败结果，不做整批回滚 |
| 列宽调整 | 支持拖拽列边界调整列宽，刷新后保持当前页面会话内设置 |
| 操作列固定 | 操作列固定在表格右侧，横向滚动时保持可见 |
| 分页 | 默认每页 20 条，支持切换（20/50/100） |
| 空状态 | 展示「暂无符合条件的线索数据」 |

### 列定义

| 列名 | 内容说明 | 宽度 |
|------|---------|------|
| 勾选列 | 复选框 | 48px |
| 线索编号 | 可点击进入详情页，链接色 | 180px |
| 公司名称 | 文本 | 180px |
| 联系人 | 文本 | 100px |
| 手机号 | 文本 | 140px |
| 邮箱 | 文本 | 180px |
| 线索来源 | 文本 Tag | 100px |
| AI评分 | 数字 Tag（配色见下） | 80px |
| 线索状态 | 状态 Tag（配色见下） | 120px |
| 归属人 | 文本 | 100px |
| 最近跟进时间 | `YYYY-MM-DD HH:mm` | 160px |
| 创建时间 | `YYYY-MM-DD HH:mm` | 160px |
| 操作 | 行内文字动作（按状态动态展示） | 120px |

### 状态 Tag 配色

| 状态 | 颜色语义 |
|------|---------|
| 各状态 | 颜色及中文文案按《线索字段清单》展示规则渲染 |

### AI 评分配色

| 分值 | 颜色 |
|------|------|
| 各评分区间 | 颜色按《线索字段清单》展示规则渲染 |

### 行内操作（按状态动态展示）

| 状态 | 展示的操作 |
|------|-----------|
| DRAFT 草稿 | 查看 / 编辑 / 作废草稿（不提供物理删除） |
| PENDING_ASSIGN/公海 | 查看 / 认领（仅 `poolType=ASSIGN_POOL`）；原负责人可撤销主动放弃 |
| ASSIGNED 已分配 | 查看 / 添加跟进 / 放弃 |
| FOLLOWING 跟进中 | 查看 / 添加跟进 / 转客户 / 放弃 |
| CONVERTED 已转客户 | 查看 |
| ABANDONED 已作废 | 查看；`voidType=VOLUNTARY_ABANDON` 时原负责人可立即撤销、其他销售在公海可见后认领；管理作废仅主管/管理员可恢复 |

## 6. 二次确认弹窗规格

| 触发操作 | 弹窗标题 | 弹窗内容 | 确认按钮 | 取消按钮 |
|----------|---------|---------|---------|---------|
| 作废草稿 | 确认作废草稿 | 作废后保留草稿记录但不可继续编辑，确认继续？ | **确认作废** | **取消** |
| 放弃 | 确认放弃 | 放弃后将退回公海；放弃原因按《线索字段清单》校验，不足时阻断并提示“放弃原因至少15字” | **确认放弃** | **取消** |
| 批量作废 | 确认批量作废 | 已选择 N 条线索。系统仅处理允许状态，统一填写放弃原因；成功项将标记为管理作废，失败项保持原状态并返回失败明细，确认继续？ | **确认作废** | **取消** |
| 转客户 | 确认转客户 | 转客户后将同步 ERP 建档，线索将变为只读且不可逆，确认继续？ | **确认转客户** | **取消** |

## 7. Mock 数据规格

### 状态覆盖要求

| 状态 | 最少条数 | 备注 |
|------|:------:|------|
| PENDING_ASSIGN | 5 | 模拟待分配；通过 `poolType` 区分待分配池与培育池 |
| ASSIGNED | 3 | 模拟刚分配 |
| FOLLOWING | 8 | 模拟跟进中（主力数据） |
| CONVERTED | 2 | 模拟已转化 |
| ABANDONED | 2 | 模拟已作废 |

**总计**：≥ 20 条

### 数据要求
- 公司名使用虚构名称（如"强盛科技"、"龙腾实业"）
- 线索编号连续：LEAD20260717-0001 ~ LEAD20260717-0020
- AI评分差异化分布：2条≥80、10条50-79、8条<50
- 手机号格式：1380001XXXX
