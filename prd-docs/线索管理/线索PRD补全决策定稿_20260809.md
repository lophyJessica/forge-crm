# 线索 PRD 补全决策定稿（标注体检驱动）

> 版本：2026-08-09 | 状态：用户已拍板"按建议"全部通过

## A. 状态定义类

### A1. 「我的线索」包含状态
- **定稿**：我的线索 = 草稿(DRAFT) + 已分配(ASSIGNED) + 跟进中(FOLLOWING)
- 理由：销售自己名下所有进行中的线索（含未提交草稿），符合销售视角
- 修改：Demo列表页#2 状态Tab定义 + 标注同步

### A2. 放弃后「撤销放弃」规则
- **定稿**：原负责人可立即撤销放弃（自己线索随时拿回）；其他销售在已作废超过 7 天后可认领
- 理由：防撞墙针对"其他销售"，不限制原负责人——两者不冲突
- 修改：主PRD 状态机/5.3流转表/6.4规则 明确"防撞墙仅约束其他销售"

### A3. 放弃时负责人/分配时间处理
- **定稿**：保留负责人，清空分配时间（撤销放弃后重新计时）
- 理由：原负责人可立即撤销（需保留归属），撤销后分配时间重置
- 修改：主PRD 5.3 放弃动作的后置影响 + 字段清单

## B. 查询区类
